# 记一数学

这是一本可以继续补的高中数学习题本。每道题写出出题意图、出题人挖的坑、如何与出题人对暗号、核心考点、翻译对照、数学思想、解题思路和规范的标准解答。首页这句话是：出题人究竟想干嘛!

数学正确性高于页面效果和文字表达。改数学内容前先看清原题条件、每一问的目标、所用知识、该年级已经学过的范围，以及解答是否完整、严谨。不得改题目条件、数学结论或原有解题思想，也不改其他题目。

做题不能只顺着题目走，得先抬头看路，知道这道题在考什么。逻辑推导和图像直观是脚手架；考点必须像钉子一样钉在页面上，学生才知道考场上要调动哪几块能力。

## 页面

- 新专题放进 `public/lectures/高一`、`高二`、`高三` 或 `高考`。文件名用「高一上期中考试16-函数入门.html」，出处写成「高一上期中考试 16题」。目录卡片写专题名、出处和这一篇的思想（与核心考点同一套说法）。题目正文同时放进目录页末尾的 `.sheet`。
- 讲义顺序：页眉、原题、整体的「想」、按原题顺序的小问、整体的「连」、`.paper` 标准解答。小问用 `data-q="第（1）问"`。前一问的结论是后一问的依据，后一问是把已有结论合起来用。每篇都要有「想」和「连」，不省略。
- 「想」是对整道题的观察：先钉住考点，再看清条件结构、各问共用什么、从哪里下手。三框之后写「核心考点」和「翻译对照」（见下节）。可用 `data-nav`，步号写「想」。「连」是把各问串起来看：条件不变时目标一换函数就换，或两个量怎么先定住一个。可用 `handoff` / `route` / `motto`。这两类是教会整体审题用的，后面小问里再次出现同类说法可以保留，不算熵增。
- 页眉 `h1` 用这一篇的数学称呼。下面第一句是标准说法，第二句是白话。页眉徽章写核心能力名（如「逻辑转化」「换元求最值」），不要只写空泛的方法词。一页里用到换元时，完整说法只在页眉写一次：由原来变量的范围确定新元的范围，二者一一对应时取值不变，计算后再代回。后面只写这一问的那一块叫什么。
- 每一问先有三框。「出题人究竟想干嘛？」只看已知和所求的关系，提出思考入口。「出题人挖的坑是什么？」见下一节。「如何与出题人对暗号？」指出题干里的哪一处在招呼某一个数学思想，并写出这个思想的名字。暗号有时是一句话或一个结构，有时是一个特殊的值，有时是几个式子凑成的组合。只点出对应，不把这个思想展开成推导。三框都不写解题步骤，不给答案，不写成标准解答。
- 思想框的标题用标准称呼，先写标准的一句，再写白话的一句。标准说法留着，白话里可以把它说成一个包。目录、页眉和小问开头不预告还没证明的数值。
- `.paper` 按试卷写：符号规范，顺序清楚，每一步有依据，步骤留全。不把前面的想法再讲一遍，也不重复已经证明的性质。
- 页面用「可以」「有兴趣就看看」。不写闯关、挑战等级、能力测评、基础、进阶、简单题、困难题，不用 `data-level`。不设积分、排名、学习记录、游戏化。不记录谁做得快、谁做得好，不展示成绩，不要求人人做完。主页不放「怎么使用这个网站」。

## 出题人挖的坑是什么？

这是警告框，用来拦住容易踩空的地方，不是解题步骤，也不给答案。

- 外层用公共类 `mindset-box pit`（样式只写在 `public/css/site.css`），红色标识。新讲义照此写，不另做一套类。
- 一句写完：先点出踩空点，再讲清为什么会踩空。例如漏掉范围、等号取不到、符号看反、两个量一起调、把没给数的参数当成一个常数。
- 不预告还没证明的具体数值当作答案；可以说「临界高度上的交点不在开区间里」，不先写出那个临界值叫读者去代。
- 框里的警告，步骤和交互文案里不再复述一遍。

## 核心考点与翻译对照

「想」里在三框之后，把这道题在考什么钉出来，并把题干里的高级说法翻成孩子听得懂的话。不另做手风琴、提示层；用已有的 `case-grid` / `case-card`、`matryoshka-box`。翻译对照是对暗号的主推手，视觉上必须压过普通思想框；样式只写在 `public/css/site.css`（`.translate-block` / `.translate-lead` / `.translate-table`），讲义页不另写一套。

- **核心考点**：用 `case-grid` 列出这一篇真正要考的能力，直白写清。例如：逻辑转化（\(\forall\)、任意 \(\rightarrow\) 最小值压过最大值）、换元求最值（复合扒马甲，回到二次或单调函数）、底数分两边。页眉徽章、目录卡片思想句与这里同一套名字。只点能力，不预告还没证明的数值答案。
- **翻译对照（对暗号主推手）**：
  - 结构：外层 `matryoshka-box translate-block`；标题固定写「对暗号 · 翻译对照」；下面一句 `translate-lead`（认出暗号 → 翻成白话 → 写成能动手的式子）；一张 `table.translate-table`（外包 `translate-wrap`）。
  - 表头三列「原题说｜白话｜执行」，副标用 `<span>` 写「暗号 / 翻出来 / 动手算」。一行一条关键转化；单元格加 `data-label`，窄屏叠排。
  - 文案：原题说保留题干符号或结构；白话用孩子能听懂的话（个子高低、穿马甲等可以，不写黑话、降维、炫技）；执行写成马上能动手的式子或操作（如 \(\min f&gt;\max g\)，令 \(t=2^{x}\) 再求最值）。
  - 视觉（由 `site.css` 统一）：左侧强调条；表头深蓝底白字；框线清楚；三列分色——原题偏灰、白话琥珀加粗（对暗号落点）、执行偏绿；不用 `overflow-wrap: anywhere`，以免公式被拆成逐字竖排。
- 考点与翻译是审题入口，不是标准解答。后面小问按它们动手，不再把同一句白话叠进思想框或步骤开头。

## 避免熵增

能删的外壳先删。真正要收的是无教学作用的空壳，以及代码叠层。

- 「想」「连」是整题审题用的，每篇都要有。核心考点与翻译对照写在「想」里，不要为了少重复而删掉。
- 小问步骤要把推导写明，不要用「证明在标准解答里」把证明推走；与 `.paper` 可以重复。
- 三框各一句。思想框是标准一句、白话一句。框里的白话，步骤里不再说一遍。暗号已经点名的思想，思想框不换个说法再叠写一次。考点卡与翻译对照已经写过的能力，不再另开一套同名思想框复述。
- 目录、页眉、小问开头、图注、挖的坑，都不预告还没证明的数值（「想 / 连」里为整题指路时除外，但仍不把未证结论写成已经算完的答案）。图已经画出要看的对象时，正文只留一句看哪里。
- 这一页自己能看完时，不指到别的讲义。不写「上一篇」「还是某某」。就写这一问没给定的是谁，所求依赖谁。
- 改已有讲义时，保留题目条件、解题方法、结论，以及「想 / 连」。只删无教学作用的空壳。发现别篇问题先报告，不擅自扩大修改范围。
- 代码同样避免叠层：一件事一处拦截或一处样式；不自定义弹层去代替够用的 `alert`；不另做手风琴去包考点。

## 解答

逻辑写全，句子写短。已证明的性质直接引用。同一个结论写一次，不拆成「至多有一个解」「解是唯一的」「恰好有一个解」。不用冗长文字代替推理。

- 严格递增只保证唯一。存在还要有值域或其他依据。必要性和充分性分开写。
- 作差证明单调性必须与人教 A 版课本定义一致，不另造表达习惯。定义：设 \(x_1,x_2\in I\) 且 \(x_1&lt;x_2\)，若总有 \(f(x_1)&lt;f(x_2)\)，则称在 \(I\) 上单调递增。作差只是把同一句话移到一边：先写 \(x_1&lt;x_2\)，再证 \(f(x_2)-f(x_1)&gt;0\)（因 \(x_1&lt;x_2\) 已固定，\(x_2-x_1\) 永远为正）；递减则证 \(f(x_2)-f(x_1)&lt;0\)。不得改算 \(f(x_1)-f(x_2)\)。四步：定区间与 \(x_1&lt;x_2\) → 作差 \(f(x_2)-f(x_1)\) 并提 \(x_2-x_1\) → 逐项定符号 → 收尾落到 \(f(x_1)&lt;f(x_2)\) 或 \(f(x_1)&gt;f(x_2)\)。一句话：定义用 \(f(x_1)&lt;f(x_2)\)，解题用 \(f(x_2)-f(x_1)&gt;0\)，二者完全一致。讲义里专设「单调性作差证明规范」时写全；同页后文作差只按规范起手，不换说法再叠一层。
- 保留关键等价变形、定义域、取值范围、存在性的依据、结论成立的必要条件。
- 用题目所在年级已经学过的知识。高一期中不用尚未学习的极限、导数，优先用函数性质、代数变形、不等式和换元。有多种解法时，用符合当前进度的那种。不为了写短而换超纲工具。
- 式子换成另一种形式，写「转化为」，不写「表为」「表出」。新字母用「令」「记」。代回写「再代回」或「计算后再代回」。
- 推导之后不再用一段文字把同一件事说一遍。不写「我们可以发现」「接下来继续观察」「这说明了什么」「因此我们不难得到」。
- 改已有讲义时，保留题目条件、解题方法和结论；删减遵循「避免熵增」。

## 画图

数形结合要画图时，只用本地的 `public/js/jsxgraphcore.js`。讲义用相对路径引入，例如 `../../js/jsxgraphcore.js`。不画静态图片，不用别的画图库，不从网上另引一份，也不手写 SVG 代替。

- 图是次主题，帮助看，不铺满正文。外层只用 `canvas-wrap`，里层是带 `jxgbox` 的 `div`。尺寸只写在 `public/css/site.css` 的 `.canvas-wrap`：宽不超过 `30rem`，居中。两张对照图可外包一层 `canvas-pair`（样式也只写在 `site.css`）。讲义页不再写图的宽度、高度或比例，也不另做一套类。
- 用 `JXG.JSXGraph.initBoard` 建板。点、线、函数图象、刻度和文字都用 `board.create`。
- 关掉版权、导航、信息框，以及平移和缩放。库没载入时，容器里写「图像未能载入。」
- 图只画这一问已经用到的对象。坐标范围、开闭点和标注与解答一致。
- 板已经画出区间、对称轴和最低点时，不再另加一条数轴。交互区只留滑块、状态文字和这张板。
- 需要自动演示时，默认静止，加「播放 / 暂停」。用 `requestAnimationFrame` 平缓往返；用户一拖滑块或点控件就立刻暂停。分界点用按钮一键到位。状态文字先写横轴上的 \(t\) 落在哪，再写代回后的最小值高度。

## 修改

`.cursor/rules/lecture.mdc` 与 `.trae/rules/lecture.md` 是同一份规则。改其中一份，另一份同时改成相同内容。

先读相关文件，只改这一处。不重构页面，不改导航和打印，不引入新的框架或依赖。改完检查页面和公式是否还能渲染。

本地静态资源引入必须带版本查询参数，避免用户缓存不刷新：

- CSS：`css/site.css?v=1`、`../../css/site.css?v=1`
- 脚本：`js/site.js?v=1`、`../../js/site.js?v=1`；有图时 `../../js/jsxgraphcore.js?v=1`
- 公式：本地链写 `vendor/tex-svg.js?v=1` 或 `../../vendor/tex-svg.js?v=1`（CDN 备用链不改）

哪个文件改了，就只把各页里**该文件**的 `?v=N` 加 1（`?v=1` → `?v=2`）。新讲义照当前各文件版本写，不另起一套。`site.js` 里拼打印页时用到的本地 `tex-svg` / `site.css` 也要带同一版本。

改完核对：数学是否正确，是否适合该年级，有没有重复推导和多余解释，页面功能是否还在。
